# Smart Task Scheduler

## Overview

Smart Task Scheduler is a Java-based console application developed using Object-Oriented Programming concepts. The project helps users manage daily tasks efficiently by providing features such as task creation, editing, searching, scheduling, analytics, reporting, reminders, and workflow management.

---

## Features

- User Registration & Login
- Create, Update & Delete Tasks
- Search Tasks by ID and Title
- Task Categories
- Priority Management
- Workflow Management
- Dependency Management
- Recurring Tasks
- Scheduler
- Notifications & Reminders
- Activity Logs
- Analytics Dashboard
- Reports
- File Handling
- Backup & Restore
- Task Statistics
- Task Filtering & Sorting
- Performance Monitoring
- Security Module

## How to Run

1. Clone the repository.
2. Open the project in VS Code or any Java IDE.
3. Compile all `.java` files.
4. Run `Main.java`.
5. Use the menu to access all features.
